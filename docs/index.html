Key Features

🎨 Glassmorphism Design

Modern glass effects with backdrop blur, transparency, and subtle borders that create depth and elegance.

📱 Responsive

Components adapt beautifully to any screen size with mobile-first responsive design principles.

⚡ TypeScript

Full TypeScript support with comprehensive type definitions for better developer experience.

🎭 Customizable

Extensive theming support with CSS variables and props for complete design control.

Getting Started

Quick Start

# Install the package
npm install react-liquid-glass

# Import and use
import { LiquidGlassButton } from 'react-liquid-glass';

<LiquidGlassButton title="Get Started" variant="primary" />
